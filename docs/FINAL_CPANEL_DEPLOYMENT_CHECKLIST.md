## 1. Passenger startup verified ✓

Root `server.js`:

- Requires `.next/standalone/server.js`
- Sets `NODE_ENV=production` when unset
- Forces `HOSTNAME=0.0.0.0` (replaces `localhost` / `127.0.0.1`)
- Honors `process.env.PORT` and `PASSENGER_PORT`
- Loads `.env*` from **project root** before standalone `chdir`
- Does **not** hardcode a listen port

**cPanel setting:** Application startup file = `server.js`

## Rollback procedure

```bash
cd /home/USER/app
git checkout <previous-good-tag>
bash scripts/deploy-cpanel.sh
# Restart Node.js app in cPanel
```

Or restore a full directory backup (including `.env` + `.next/standalone`), then Restart.

Tag every production deploy (`v0.1.0`, `v0.1.1`, …).

## Go-live (operator)

1. Application root = project folder  
2. Startup file = `server.js`  
3. Node.js = **20.x** (or newer 20+)  
4. Set production env vars (no localhost URLs)
